## Sistema de Notificações

Exercício proposto pela Claude (Anthropic) para praticar Interfaces em Java.

### Conceitos praticados:
- Interface (`Notifiable`)
- Composição (`NotificationLog`)
- Streams (`filter`, `count`)
- Tratamento de exceções (`try-catch`, `IllegalArgumentException`)
- Extração de métodos (Extract Method)
- Switch expression (`switch` com `->`)
